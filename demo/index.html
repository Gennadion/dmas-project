Agents that leave receipts

A recorded run of a decentralized multi-agent system (a LangGraph reimplementation of Ding et al., arXiv:2512.02410). Every request and response between agents was committed on a public blockchain, so you don't have to trust this page: press Verify and your browser re-checks each exchange against the chain itself.

How one exchange works

  1. The proxy agent commits the hash of its request on-chain (commitRequest).
  2. The service agent checks the request against that hash, encrypts its answer under a fresh key κ, and commits the ciphertext's hash and its price η (commitResponse).
  3. The proxy agent checks the ciphertext against that hash and pays η on-chain (fulfillCondition).
  4. Seeing the payment on-chain, the service agent releases κ and the proxy agent decrypts the answer.

Only hashes and payments go on-chain. This page publishes each exchange's ciphertext and κ, which is what lets anyone confirm what the service agent committed to.
